API Access

Developer guide for Forgensic APIs.

Submit documents, poll status, and retrieve summary-only results. Rendered previews are optional and served once.

Document Forgery Detector API

Use the API to run tamper detection, track processing progress, and keep data privacy intact. Images are never stored and previews are served once.

Python FastAPI OpenCV

Quick facts

  • Base URL: use your backend host (example: http://127.0.0.1:8000)
  • Auth: Bearer token (Firebase ID token) or disable auth in dev
  • Uploads: PDF, JPG, PNG, TIFF, BMP, WEBP (max 10 MB)
  • Preview files are served once, then deleted from memory

1) Quick start

Replace BASE_URL with your running backend. If auth is enabled, set TOKEN to a Firebase ID token.

BASE_URL="http://127.0.0.1:8000"
TOKEN="YOUR_FIREBASE_ID_TOKEN"
Docs are available at BASE_URL/docs and OpenAPI JSON at BASE_URL/openapi.json.

2) Endpoints

Method Path Description
POST /jobs Create a job and upload a document (multipart)
GET /jobs/{job_id} Poll job status and progress
GET /jobs/{job_id}/results Fetch summary-only results payload
GET /jobs/{job_id}/files/{file_name} One-time preview bytes for a rendered page image
GET /health Service health check

3) Upload a document

Send a file as multipart/form-data. The response returns a job_id you can poll.

curl -X POST "$BASE_URL/jobs" \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@/path/to/document.pdf" \
  -F "ocr_enabled=true"

4) Poll status

Use the job_id from the upload response.

curl -X GET "$BASE_URL/jobs/JOB_ID" \
  -H "Authorization: Bearer $TOKEN"

5) Fetch results

Results are summary-only, with per-page categories and regions. No images are stored.

curl -X GET "$BASE_URL/jobs/JOB_ID/results" \
  -H "Authorization: Bearer $TOKEN"

6) One-time preview

If a page has image_url, you can fetch it once. A second request returns 404 by design.

curl -L "$BASE_URL/jobs/JOB_ID/files/PAGE_001.png" \
  -H "Authorization: Bearer $TOKEN" -o preview.png
Preview bytes are cached in memory only and evicted after the first fetch.

8) Auth and privacy

Auth is enforced when AUTH_REQUIRED=true. For local demos, set AUTH_REQUIRED=false to skip token checks.

Files are deleted after processing. Rendered previews are cached in memory and served once.
